# TC Lens v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Store one editable TC Lens message per episode, expose it through the custom WordPress REST API, and open TC Lens with the episode ID from the streaming player.

**Architecture:** Reuse the existing `tc_lesson` post and custom post-meta storage. Add the message to both existing episode editing surfaces, return it from the existing lesson endpoint, add it to the Angular `Lesson` model, and build the TC Lens URL from the current lesson ID. Do not add timestamps, timelines, ACF, entities, or a `postMessage` bridge until Arun confirms the transport.

**Tech Stack:** WordPress/PHP custom plugin, WordPress REST API, Angular 22/TypeScript, Vitest/Angular test runner, existing admin AJAX and course-builder forms.
